# 🐍 Retro Snake

A classic **Snake game** built from scratch using **C++** and **Raylib**, inspired by the simple and nostalgic arcade games of the past.

## 🎬 Trailer

[▶️ Watch the Trailer](./trailer.mp4)

## 🎮 About

**Retro Snake** is a simple recreation of the classic Snake game.

Control the snake, collect food, grow longer, and try to achieve the highest score without hitting the walls or yourself.

The project was created as a hands-on experience with **C++ game development** and the **Raylib** library.

## ✨ Features

* 🐍 Classic Snake gameplay
* 🍎 Food & snake growth
* 🏆 Score system
* 💥 Collision detection
* 🎮 Keyboard controls
* 🕹️ Retro-inspired visuals
* ⚡ Built with C++ and Raylib

## 🎮 Controls

| Key              | Action     |
| ---------------- | ---------- |
| ⬆️ `Up Arrow`    | Move Up    |
| ⬇️ `Down Arrow`  | Move Down  |
| ⬅️ `Left Arrow`  | Move Left  |
| ➡️ `Right Arrow` | Move Right |
